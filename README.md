# AI-Content-Performance-Analysi

## Project Overview
This project analyzes AI-generated content performance across different social media platforms using Python and Power BI.

## Objectives
- Analyze content performance.
- Compare engagement across platforms.
- Identify top-performing content.
- Provide business insights and recommendations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Microsoft Excel

## Dataset
- GenAI Media Performance 2026 Dataset

## Project Files
- GenAI_Media_Performance_Final.csv
- python to power bi.xlsx
- Dashboard.pbix
- Dashboard1.jpeg
- Dashboard2.jpeg
- AI gen pdf.pdf
- Jupyter Notebook (.ipynb)

## Visualizations
- Count Plot
- Histogram
- Bar Chart
- Box Plot
- Violin Plot
- Pie Chart
- Scatter Plot
- Correlation Heatmap
- Area Chart
- XY Plot
- Pivot Table

## Key Insights
- Platform-wise engagement varies significantly.
- High engagement content generates better revenue.
- AI tools improve content performance.
- Data visualization helps identify business trends.

## Conclusion
This project demonstrates how Python and Power BI can be used together to analyze AI-generated content and support data-driven business decisions.
